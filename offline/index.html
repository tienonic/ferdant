Open your file & know its limits

Download, then open the HTML file from Downloads or Files in a browser. If a phone shows a file preview, choose a browser to use the tools. Try it with your connection off; your browser’s Print command also makes a paper copy.

Local numbers, saved guides, search and tools work offline. Website links and alert signup need internet; calls need phone service. This is a dated copy, with no live alert, outage or shelter feed. Download a fresh edition when details change.

Tools keep inputs in the open page only. Closing the file does not save your notes. No location detection, account or installation is needed.
