# ZIP-area resource search — November 3, 2026

The existing location search accepts California ZIP codes, with a ZIP code option beside City and County. Five-digit codes and ZIP+4 entries work with keyboard or pointer selection. ZIP+4 is reduced to its five-digit area; no address is inferred. Unmapped or non-California codes show an explicit fallback to city/county search.

## Map behavior

The map centers a 5 km search circle on the Census ZIP-area reference point. It shows all listed resources within that radius and retains the existing nearby/county fallback when a resource category has no local match. Resource cards state straight-line distance from the ZIP-area center. Different ZIP areas within the same city produce different resource lists: the checked directory returned 133 mapped places around 90012 and 33 around 90045. These are directory counts, not confirmed current openings.

A ZIP area can cross counties. The map loads the service directories for all California counties with land overlap in the saved relationship file. For ZIP 95616, that includes Yolo and Solano. Phone contacts, risk ratings and the PDF booklet remain explicitly scoped to the primary county, chosen by largest California land overlap. The page identifies any other overlapping counties. ZIP lookup does not create ZIP-specific hazard ratings or assign a government jurisdiction to an address.

The complete offline website retains the ZIP focus, regional service data, visit facts and eligible planning overlays. Planning-overlay cache keys include the ZIP code so another ZIP in the same county cannot inherit the saved geometry. The county PDF retains its county title and street-map extent. Changing to a city or county clears ZIP focus.

## Sources and limits

`content/california-zip-areas.json` contains 1,808 California-associated Census ZIP Code Tabulation Areas (ZCTAs), including 169 with multiple California counties. It uses:

- [2025 Census Gazetteer ZIP-area reference points](https://www2.census.gov/geo/docs/maps-data/data/gazetteer/2025_Gazetteer/2025_Gaz_zcta_national.zip), published September 10, 2025.
- [2020 ZCTA-to-county relationships](https://www2.census.gov/geo/docs/maps-data/data/rel2020/zcta520/tab20_zcta520_county20_natl.txt), published December 9, 2021. The [record layout](https://www.census.gov/programs-surveys/geography/technical-documentation/records-layout/2020-zcta-record-layout.html) defines county overlaps and land-area units.

Both were retrieved November 3, 2026. Source byte counts and SHA-256 hashes are saved in the projected file; the generated reference catalog hashes the projection itself. `scripts/project-zip-areas.py --input-dir PATH` reproduces it from those two public input files. Normal builds perform no download or refresh.

ZCTAs approximate postal areas; the reference point is not a household address or an address geocoder. The circle is a search radius, not a postal boundary. Some PO-box, unique and newly assigned ZIP codes have no mapped area. Cross-state areas retain their original Census reference points; only California county directories are included. Public directory coverage and source dates remain visible. The search makes no geolocation request and adds no cookies or browser storage.
